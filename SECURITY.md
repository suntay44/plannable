# Security policy

## Supported versions

Security fixes are provided for the latest released version of Plannable.

## Report a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/suntay44/Plannable/security/advisories/new). Do not open a public issue with exploit details, secrets, or private plan content.

Include the affected version, operating system, Node.js version, reproduction steps, impact, and any suggested mitigation. You should receive an acknowledgement within seven days.

Plannable reads and writes project-local planning files. A report is especially helpful if it shows unexpected access outside the working project, unsafe handling of symbolic links, or a package supply-chain concern.
