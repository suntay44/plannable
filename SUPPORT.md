# Support

Use [GitHub Discussions](https://github.com/suntay44/Plannable/discussions) for usage questions and workflow ideas.

Use a [bug report](https://github.com/suntay44/Plannable/issues/new?template=bug_report.yml) for reproducible defects. Include the Plannable version, Node.js version, operating system, command, and a minimal redacted plan.

Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
